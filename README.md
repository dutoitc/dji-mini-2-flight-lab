# DJI Mini 2 Flight Lab

Simulateur pédagogique de drone dans le navigateur, inspiré du DJI Mini 2. Projet indépendant, non affilié à DJI.

## Objectif

Terrain procédural avec arbres et collines, commandes clavier en mode 2, collisions, décollage et atterrissage, télémétrie et publication GitHub Pages.

## Commandes prévues

- W / S : monter / descendre
- A / D : tourner à gauche / droite
- Flèches : avancer / reculer / déplacement latéral
- 1 / 2 : incliner la caméra
- § : vue verticale
- Espace : décoller
- L : atterrir
- R : réinitialiser

Implémentation et publication en cours.
